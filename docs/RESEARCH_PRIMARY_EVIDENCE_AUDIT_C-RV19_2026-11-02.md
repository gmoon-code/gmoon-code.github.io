The manuscript also states the item-specific Unit 2 pathway criteria. The website correctly reported this as a **proposed assessment premise**. The original study's prompt is not to be retroactively rewritten to say it asked about electrolyte-related cardiac arrest.

It explicitly narrows the Unit 2 completeness interpretation to that proposed task premise. Both original physiological reports are now linked in the page.
