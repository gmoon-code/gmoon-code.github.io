## One justified improvement to public text

In the five-pair table under **Reconstructing the same mechanism**, the existing first row overstated what **every** extended case had added.

**Before:**

> Additional intermediate causal connections appeared following correction.

**After, committed:**

> Later reconstructions added missing causal connections or extended earlier pathways through to plant death.

**Rationale:** The earlier sentence works for cases where reconstructions add missing intermediate relationships, but wrongly treats **all five extensions** as newly expressed *intermediate* steps. Two linked records chiefly carry already articulated ATP/NADPH/carbon-fixation chains to the downstream outcome. The revised wording correctly differentiates these legitimate forms of pathway extension. It also avoids claiming that correction alone *caused* the new wording, a crucial condition because feedback and task prompting changed together. The correction is concise, natural, consistent with the author's gentle academic voice, and fits the adjacent table rows without adding an inflated conclusion or rhetorical contrast.

The exact change was committed to `research-action.html` as GitHub commit **[`717493c`](https://github.com/gmoon-code/gmoon-code.github.io/commit/717493c4d7a4c35b3f90bc9d926ce5dde639c698)**.
