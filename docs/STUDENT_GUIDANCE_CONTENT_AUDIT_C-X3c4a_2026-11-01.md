## Identified issues and direct revisions

1. **Unconfirmed resources stated as if accessible.** `access1` now distinguishes intended sources from actual permissions, licences and available equipment. The revised hypothetical greenhouse example marks access unconfirmed. `resources` replaces an obsolete nine-container example with the coherent **18-dish / 90-seed** proposed salinity design, names the shoot-length ruler and keeps laboratory approval and supervision pending. These are instructional planning numbers, not findings or a validated sample-size calculation.
2. **Example context and Canadian English.** `contextPop` now uses radish seeds and labelled dishes to match the already audited exemplar. `timeLimit` now uses `analysing` and explains that access/permissions and writing time belong within the actual project timeline; its six-week schedule is explicitly illustrative, not the visitor's real available time.
3. **Preliminary searches versus searches performed.** `prelimSearch` previously described a record of searches already used and instructed the student to report what each search taught them, while the corresponding actual good response consisted of queries **not yet run**. The revised `meaning`, `write`, `example`, questions and warning distinguish planned strings from executed searches. Actual query, platform, date, records and changes are required for reporting searches genuinely run. This is consonant with Cochrane Handbook Chapter 4, https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-04, and Columbia University health sciences library guidance, https://library.cumc.columbia.edu/kb/developing-and-validating-comprehensive-literature. These references describe good reproducible search practice; the introductory activity is **not** misrepresented as a full systematic-review search.
4. **Unverified literature claims.** `known` now permits a *labelled candidate claim to check* when no publications have yet been examined, and requires source-supported agreement before describing a pattern as established. `methodsSeen` distinguishes source-extraction categories **planned** from methodological patterns **observed in checked studies**; its example is explicitly a proposed extraction table. `uncertain` distinguishes an unresolved, source-documented tension from a hypothetical comparison still requiring examination. No literature findings or source records were invented.
5. **Research-question development.** The `questionShift` example now explicitly identifies a hypothetical reading exercise, so it does not assert a completed review; its observation-versus-assignment reasoning is preserved. `rq2` now uses the qualitatively distinct student-description question already established in the reviewed response-example sequence. The guide explains that the second candidate should genuinely change the question's evidence or conceptual purpose, rather than merely adjusting wording.

Fifteen entries were retained without superficial rewriting. Their questions and cautions were already coherent, appropriately bounded and consistent with research-design options in the established curriculum. All revisions preserve the field keys and the visitor-facing student help structure.
