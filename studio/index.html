How do I get a token? (one-time setup)
  1. Open GitHub's fine-grained token page and sign in to gmoon-code.
  2. Choose Only select repositories and select gmoon-code.github.io.
  3. Under Repository permissions, set Contents to Read and write. No other write permissions are needed.
  4. Set an expiration, create the token, and paste it above. Keep the token private, like a password.

The token is sent only to GitHub's API to verify ownership and save your changes. It is never added to the website files. You can sign out at any time.

Editing, without the guesswork

  1. Choose a page on the left. New pages start with a simple title and section.
  2. Click an item in the preview to select it. Edit its words in Content or double-click text directly in the preview.
  3. Add something using the Add menu above the preview. Select a section first if you want to add a block inside it.
  4. Rearrange or remove using the actions in Content. Undo is available at the top.
  5. Change the look in Design. Width, height, spacing, and optional pixel offsets live in Position.
  6. Check phone and tablet previews, then choose Publish changes. All changes publish together; until then, the public website is untouched. For bold or italic text, double-click a paragraph and use the usual Ctrl+B or Ctrl+I shortcuts.

For images, add an Image block or select an existing image and choose Replace image. Describe each image briefly for visitors who cannot see it.
