How do I get a token? (one-time setup)
  1. Open GitHub's fine-grained token page and sign in to gmoon-code.
  2. Choose Only select repositories and select gmoon-code.github.io.
  3. Under Repository permissions, set Contents to Read and write. No other write permissions are needed.
  4. Set an expiration, create the token, and paste it above. Keep the token private, like a password.

The token is sent only to GitHub's API to verify ownership and save your changes. It is never added to the website files. You can sign out at any time.

Editing, without the guesswork

  1. Choose a page on the left. New pages start with a simple title and section.
  2. Tables can be added through Browse layouts. Select or double-click a cell to edit it, then use the Table controls to add or remove rows and columns. Merged-cell layouts are protected from structural changes.
  3. Click an item in the preview to select it. Edit its words in Content or double-click text directly in the preview.
  4. Add something using the Add menu above the preview. Select a section first if you want to add a block inside it.
  5. Rearrange or remove using the actions in Content. Undo is available at the top.
  6. Work directly on the page with the contextual Add content and Section buttons. Click a container in the selection path to edit an entire group. Quick layout offers width, alignment, full-row positioning, and copying a visual style between items.
  7. Change the look in Design. Width, height, spacing, and optional pixel offsets live in Position.
  8. Check phone and tablet previews, then choose Publish changes. All changes publish together; until then, the public website is untouched. For bold or italic text, double-click a paragraph and use the usual Ctrl+B or Ctrl+I shortcuts.

To rearrange something, click it and drag its green Move handle. A colored insertion line shows where it will land. You can also use Earlier and Later or press the arrow keys while the Move handle is focused. To resize anything, click it and drag the blue corner or edge handles. For a divider, use its endpoints and thickness handle. To undo a resize, choose Undo or Reset size. Images keep their proportions by default, and text remains readable. For exact pixel sizes, use Position.
