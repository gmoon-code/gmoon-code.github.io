# Ye Eun Moon Academic Website

A static multi-page academic website for Ye Eun Moon, hosted with GitHub Pages.

The site is designed as an academic portfolio that complements the CV rather than repeating it. It separates research, teaching, and design work into dedicated pages and uses the same Moon Notes visual language established in the Research Methods Studio and The Story Method.

Planned public URL: https://gmoon-code.github.io/
