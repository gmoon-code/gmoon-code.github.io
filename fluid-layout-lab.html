Fluid layout lab

Experimental visual builder · browser-local drafts · no publication

Existing editor

Import an existing page

Creates an editable layout proposal from the page’s text and images. Original HTML and styles are preserved on the website. Import does not publish or overwrite anything.

Add blocks

Select a block, drag it to move, or drag its bottom-right corner to resize. Use the arrow keys to move the selected block. Shift + arrows resizes it.

Properties

Select a block to edit its properties.

Editing desktop positions

This is an isolated prototype. Exported JSON is a layout proposal and is not connected to your live pages or publishing workflow.
